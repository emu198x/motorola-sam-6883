# motorola-sam-6883

The Motorola MC6883 synchronous address multiplexer.

| Crate | Registry |
|---|---|
| [`emu198x-motorola-sam-6883`](crates/emu198x-motorola-sam-6883) | [crates.io](https://crates.io/crates/emu198x-motorola-sam-6883) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Dragon 32 and 64.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
